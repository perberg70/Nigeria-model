# Nigeria net electricity imports — Our World in Data / Ember

- **Source:** Our World in Data, `net-electricity-imports`,
  https://ourworldindata.org/grapher/net-electricity-imports.csv (underlying data: Ember).
- **Retrieved:** 2026-08-06.
- **Units:** TWh. **Negative = net exporter.**

## File

`net_electricity_imports_nigeria.csv` — the Nigeria rows of the export.

## Use

Explains part of the difference between electricity generated and electricity consumed in Nigeria
(the rest is losses and own use).

## Caveats

- Ember is a different source from the IEA figures used elsewhere, so combining the two is
  indicative only.
- Values are exactly 0 for 2010–2015 and non-zero from 2016. Nigeria has supplied Niger, Benin and
  Togo for longer than that, so the early zeros most likely mean "not reported".
